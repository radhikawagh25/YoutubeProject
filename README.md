# 📺 YouTubeProject

A full-stack YouTube clone web application that allows users to watch videos, interact with content, and experience a modern video-streaming platform interface..

---

## 🚀 Project Overview

**YouTubeProject** is a video streaming web application inspired by YouTube.
It provides features like video playback, user interaction, and responsive UI design.

The project is built using modern frontend and backend technologies to simulate a real-world video platform.

---
## 🔗 Live Project Link

Frontend is deployed on Vercel:

👉 https://youtube-project-fmbb.vercel.app/

---

## ▶️ How to View Videos (Important)

Since the backend server is not deployed, you must run it locally to load videos.

### Steps:

1️⃣ Open the live project link in your browser:

```
https://youtube-project-fmbb.vercel.app/
```

2️⃣ Open the project in **VS Code**

3️⃣ Go to the backend folder:

```bash
cd server
```

4️⃣ Start backend server:

```bash
npm start
```

or

```bash
node index.js
```

5️⃣ Once the server runs successfully ✅

* Refresh the website
* Videos will appear and play properly

---

⚠️ Note:
If backend is not running, videos will not load because APIs are served from the local server.

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/snehalbolke13/YoutubeProject.git
cd YoutubeProject
```

---

### 2️⃣ Install Dependencies

#### Frontend

```bash
cd yourtube
npm install
```

#### Backend

```bash
cd ../server
npm install
```

---

### 3️⃣ Run Project

#### Start Backend Server

```bash
cd server
npm start
```

or

```bash
node index.js
```

---

#### Start Frontend

```bash
cd yourtube
npm run dev
```
